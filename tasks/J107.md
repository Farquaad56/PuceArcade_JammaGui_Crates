## Spécification (décidée, ne pas réinterpréter)
Reprendre input.rs / controls_menu.rs en remplaçant les actions Neo Geo (A-D, Select, mahjong) par les actions JAMMA :
`P{n}Up, P{n}Down, P{n}Left, P{n}Right, P{n}B1..P{n}B6, P{n}Start` pour n = 1..4 (44 actions), `Coin1..Coin4, Service, Test, Tilt` (7) : `N_ACTIONS = 51`.
Touches par défaut : J1 flèches, B1 Z, B2 X, B3 A, B4 S, B5 Q, B6 W, Start Entrée ; J2 I/K/J/L, B1 G, B2 H, B3 T, B4 Y, B5 U, B6 O, Start P ; Coin1 5, Coin2 6, Coin3 7, Coin4 8, Service 9, Test F2, Tilt aucune ; J3-J4 aucune touche.
Manettes (gilrs, manette n -> joueur n, n ≤ 4) : croix + stick gauche (seuil STICK_THRESHOLD), South B1, East B2, West B3, North B4, LeftTrigger B5, RightTrigger B6, Start = Start, Select = pièce du joueur.
`pub fn to_jamma(&self) -> JammaInputs` (fonction de l'état, sans egui) ; `Bindings::from_prefs/to_prefs` avec les noms d'actions ci-dessus. La fenêtre de configuration n'affiche que les boutons `1..=info.buttons` et les joueurs `1..=info.players`.
