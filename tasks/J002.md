## Spécification (décidée, ne pas réinterpréter)
`pub struct TestBoard` implémente `JammaBoard` et `BoardDebug` ; `TestBoard::new(rotation: Rotation)`. Tout est déterministe.
- info : system "Test", name "mire" (ou "mire_v" si rotation != Rot0), title "Mire de test JAMMA", players 2, buttons 6, video `{ width: 288, height: 224, refresh_hz: 60.0, aspect: (4, 3) si Rot0/Rot180 sinon (3, 4), rotation }`, audio `{ sample_rate: 48000.0, channels: 1 }`, une banque `DipBank { name: "DSW", default: 0xFF }`, deux switches : `{bank 0, mask 0x01, label "Grille", default 0x01, settings [("Non", 0x00), ("Oui", 0x01)]}` et `{bank 0, mask 0x06, label "Vitesse du curseur", default 0x06, settings [("1", 0x06), ("2", 0x04), ("3", 0x02), ("4", 0x00)]}`, has_analog false.
- État : frame (u64), curseur (x, y) i32 initial (140, 108), inputs, dips (1 octet), layer_mask u32 = 0b111, pixels Vec<u32> 288×224.
- run_frame : vitesse v = 1 + (3 - ((dips >> 1) & 3)) (soit 1, 2, 3, 4 pour 0x06, 0x04, 0x02, 0x00) ; curseur += v selon les directions du joueur 1, borné à [0, 280] × [0, 216] ; frame += 1 ; redessiner : fond 0x202020 ; si couche 0 : 8 barres verticales de 36 px sur y 0..111 : 0xFFFFFF, 0xFFFF00, 0x00FFFF, 0x00FF00, 0xFF00FF, 0xFF0000, 0x0000FF, 0x000000 ; si couche 1 et dips bit0 : grille 0x808080 sur y ≥ 112 aux pixels où x % 16 == 0 ou y % 16 == 0 ; témoins des boutons (toujours) : pour n = 0..12 (J1 B1..B6 puis J2 B1..B6) carré 8×8 en (8 + 12n, 200) couleur 0x00FF00 si appuyé sinon 0x004000 ; si couche 2 : curseur 8×8 blanc en (x, y).
- Audio : 800 échantillons par trame (48000 / 60) ; si J1 B1 appuyé : carré 1 kHz amplitude 0,25 (compteur global d'échantillons s : +0,25 si (s / 24) pair, sinon -0,25), sinon 0,0.
- save_state : octets `b"MIRE"` + frame (u64 LE) + x, y (i32 LE) + dips (u8) + compteur audio (u64 LE) ; load_state vérifie l'en-tête et la taille (Err sinon).
- BoardDebug : cpus = [CpuView { name "MIRE", pc: frame as u32, registers [("X", x), ("Y", y)], address_bits 16 }] ; peek(0, a) = octet a % 8 de frame (LE) ; step_instruction = run_frame ; registers = [("Mire", [("Trame", frame en décimal)])] ; images = [DebugImage { name "Barres", 8×1, les 8 couleurs }] ; layer_names = ["Barres", "Grille", "Curseur"] ; set_layer_mask.
- `driver.rs` : `pub struct TestDriver { pub saves: PathBuf }` implémente `BoardDriver` : system_name "Mire JAMMA", games = [mire (Rot0), mire_v (Rot270)] tous available/supported, default_game Some("mire"), load crée la TestBoard correspondante (nom inconnu -> Err).
