## Spécification (décidée, ne pas réinterpréter)
Reprendre la structure de `ref/puce16-neogeo/ng-gui/emu_thread.rs` avec le contrat :
```rust
pub enum Cmd { Load(String), Reset, Pause(bool), Inputs(JammaInputs), Dips(Vec<u8>), SaveState(u8), LoadState(u8), Step, FrameAdvance, LayerMask(u32), Screenshot, Quit }
pub enum Event { Loaded(BoardInfo), LoadError(String), Frame { pixels: Vec<u32>, info: VideoInfo, frame: u64 }, Audio(Vec<f32>), Stats { emu_ms: f32 },
                 Saved(u8), StateError(String), ScreenshotSaved(PathBuf), Debug(DebugSnapshot) }
pub struct DebugSnapshot { pub cpus: Vec<CpuView>, pub registers: Vec<(String, Vec<(String, String)>)>, pub images: Vec<DebugImage>, pub layer_names: Vec<String> }
pub fn spawn(driver: std::sync::Arc<dyn BoardDriver>) -> (Sender<Cmd>, Receiver<Event>, JoinHandle<()>);
pub fn step_once(board: &mut dyn JammaBoard, inputs: &JammaInputs) -> (Vec<u32>, Vec<f32>);   // fonction pure testable : set_inputs, run_frame, copie video, take_audio
pub fn frame_period(refresh_hz: f64) -> std::time::Duration;   // Duration::from_nanos((1e9 / refresh_hz).round() as u64)
```
Cadence : une trame toutes les `frame_period(info.video.refresh_hz)` (Instant, rattrapage limité à 3 trames). Savestates : `<saves_dir>/<jeu>.s<slot>`. Captures (`capture.rs`) : PNG (crate png) de l'image native APRÈS rotation, `<saves_dir>/<jeu>_<trame>.png`. Le `DebugSnapshot` n'est envoyé qu'après `Step`/`FrameAdvance` ou en pause quand le débogueur est ouvert (commande implicite : envoyé à chaque `Step`).
